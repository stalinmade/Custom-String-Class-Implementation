# Custom String Class in C++

A custom String class implemented in C++ to understand **classes, constructors, dynamic memory allocation, operator overloading, friend functions, and string manipulation** without directly relying on the standard `std::string` class.

### Features

* Default, parameterized, and copy constructors
* Dynamic memory allocation using `new` and `delete`
* Assignment operators
* `+` operator for string concatenation
* `[]` operator for character access and modification
* String comparison operators
* Input and output operator overloading
* Custom implementations of:

  * Strcpy()
  * Strncpy()
  * Strcat()
  * Strncat()
  * Strcmp()
  * Strncmp()
  * Strlen()
  * Strrev()
  * Strchr()
  * Strrchr()
  * Strstr()
  * Strupper()
  * Strlower()

### Concepts Practiced

* Object-Oriented Programming
* Encapsulation
* Deep Copy
* Dynamic Memory Management
* Operator Overloading
* Friend Functions
* Pointers and Character Arrays
* C/C++ String Manipulation

This project was developed to strengthen my understanding of **C++ memory management and object-oriented programming concepts** by building a string class from scratch.
